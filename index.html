Registration Information

Students must satisfy all the given conditions before registering for a course.

The system checks each condition and gives the final registration result.

If even one requirement is not fulfilled, the registration cannot be completed.

Logic Behind the System

Four conditions are represented using propositions. All four conditions are connected using AND.

(P ∧ Q ∧ R ∧ S) → T

P = Fees Paid
Q = Prerequisite Completed
R = Seats Available
S = No Timetable Clash
T = Registration Successful

Working of the Portal

When all four conditions are selected, the system considers the student eligible for registration. If any condition is missing, registration is rejected.
